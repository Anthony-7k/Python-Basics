## 本轮完善

1. 本地数据库备份后从迁移 0002 升级到 0006，保留已有数据。
2. 数据库事务写入失败先回滚再记录失败状态与事件，避免任务永远显示处理中。
3. 结构化日志保留异常堆栈。
4. 同类文档有多份时产生高风险，暂停自动关联和三单比较，不任意选择最后一份。
5. 就绪检查验证必需表与字段，旧数据库返回 503；启动说明补充迁移步骤。
6. 五组原始 PDF 固化为便携测试材料，自动化覆盖识别、字段证据、风险与审批。

## 边界

这些材料是带文本的原生 PDF，不代表扫描件 OCR 验收。真实 OCR、病毒扫描、复杂多单匹配与 Docker 运行验收仍未完成。人工匹配界面仍需开发；当前多单据采用显式高风险阻断，不能自动批准。

生成器拒绝覆盖已有材料；验收脚本会创建案件并执行审批，仅用于开发环境。
