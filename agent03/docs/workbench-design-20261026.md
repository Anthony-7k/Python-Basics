# 工作台视觉改版 · 2026-10-26

按用户确认的深色导航 / 浅色工作区预览实现。改动限于前端及测试，没有改动认证、数据库、Provider、审批条件或上传限制。

## 布局

- 深蓝侧栏：案件工作台、制度知识库、管理员审计、真实租户/用户、退出。
- 运营概览：日期筛选/重置、四项核心统计、人工修正率、规则命中率、风险分布、案件状态及报告数量，均使用接口数据。
- 案件工作区：左侧搜索、状态筛选、分页与可滚动案件表；右侧为选中案件的材料、流程阶段、进度、失败信息、当前风险摘要及全部操作。
- 桌面宽度大于 1250px 使用双栏；窄屏改为上下布局；手机侧栏改为顶部导航，案件表独立横向滚动。支持键盘焦点、语义化按钮和减少动态效果设置。
- 不展示未实时验证的“模型已连接”。模型名称、来源和 Token 仍从文档的抽取结果查看。

## 功能保留对照

| 功能 | 改版后位置 |
| --- | --- |
| 登录 / 多租户选择 | 登录页，原流程保留 |
| 租户、用户、退出 | 导航底部；手机导航下方 |
| 新建案件 | 工作区右上 |
| 日期统计筛选 / 重置 | 运营概览右上 |
| 搜索 / 状态 / 刷新 / 分页 | 案件列表 |
| 材料上传 / 文件类型与大小校验 | 右侧详情，仍为 DRAFT 且有提交权限时可用，25 MB |
| 删除材料 | 草稿文件的删除按钮与确认框 |
| 提交 / 失败重试 | 右侧详情，保留原状态与角色限制 |
| 阶段、进度、失败原因、Trace | 案件详情与处理历史 |
| 抽取 / OCR 与模型来源 / 用量 / 原文证据 | 每个文件的“查看抽取”弹窗 |
| 字段修正与原因 | 抽取弹窗，保留权限校验；修正后刷新案件版本 |
| 三单比较 / 候选文件 / 风险 | 三单审查弹窗，手机下三列改纵向 |
| 风险处置、理由、制度引用 | 原审查弹窗保留；处置后刷新摘要与版本 |
| 批准 / 驳回 | 右侧审批，后台风险和版本约束不变 |
| 报告生成 / 下载 / 失败重试 / 生成进度 | 右侧详情及历史；已完成报告也可从列表下载 |
| 历史任务 / 事件时间线 / 报告哈希 | 处理与报告历史 |
| 制度检索列表 / 管理员上传版本 | 制度知识库 |
| 审计筛选 / 分页 / 变更 / Trace | 管理员审计记录 |

详情按钮保持直接可见，没有依赖“更多”菜单隐藏业务操作。视觉稿中的示例统计、日期和连接标识不作为真实状态写入应用。
