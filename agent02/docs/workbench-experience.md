# FlowPilot 工作台体验更新

更新日期：2026-10-26。

本轮完善工作台使用流程及页面，保留现有的模型规划、知识库、工具、权限和审批接口。新增的身份接口只暴露经过验证的用户信息与非敏感运行模式。

## 使用方式

1. 登录后进入工作台，填写目标或选择场景模板。支持 Ctrl / Command + Enter 提交，输入限制为 4000 字符。
2. 草稿仅保留在当前浏览器会话中，按工作区与用户分别存储。
3. 提交后自动定位到执行区域。可以切换执行结果、工具调用和执行轨迹；移动端选择历史任务后自动定位到详情。
4. 任务列表支持目标、编号和回答搜索，也可按待审批、已完成、失败或超时筛选。列表最多加载最近 100 条，统计卡片仅针对这些记录。
5. 创建任务时，审批人可直接修改标题、截止日期，也可以切换 JSON 编辑。拒绝操作需要填写原因并确认。
6. 可重试的失败任务提供恢复入口。审批拒绝不会被当成执行故障，也不会提供自动恢复按钮。
7. 已有结果支持复制和导出 Markdown 记录。引用可以展开原文片段；只有 HTTP 或 HTTPS 来源地址显示为外部链接。
8. 服务状态使用数据库就绪检查；登录过期会返回登录页，草稿仍按原工作区保存。

## 状态与统计口径

- 工具成功图标只出现在实际成功的调用结果上；待审批、未执行和失败均显示独立状态。
- 同一次工具调用恢复后，展示最新一次尝试的结果。
- 没有已结束任务时，成功率显示为不可用，不显示虚假的 100%。
- 成功率为完成数除以完成、失败、超时之和，排除人工审批拒绝。
- 历史任务使用已保存的工具调用还原步骤，不伪造已丢失的实时事件。实时 SSE 事件仅在当前页面会话中保留。
- 任务标题优先使用原始目标，审批修改的是待执行操作参数，原始目标仍留存。

## 范围与限制

本轮浏览器验收使用规则 Planner 与示例知识库，没有产生额外的真实模型 API 调用。搜索和任务工具仍为本地演示适配器；尚未增加动态重新规划、企业 SaaS 连接和持久后台任务队列。真实模型和真实知识库效果需要另外运行对应的端到端评测。
