# Changelog

## 2026-10-26 工作台体验更新

- 统一 FlowPilot 工作台、任务记录、审批中心和移动端布局，移除在线字体依赖。
- 新增任务搜索与筛选、按工作区与用户保留的会话草稿、快捷执行、结果复制与导出。
- 新增表单式审批和拒绝原因确认；工具状态与真实调用结果对应，未执行的工具不再显示成功。
- 新增 `/api/v2/workspace`，从已验证身份读取工作区和权限，服务状态通过 `/ready` 检查。
- `TaskView` 返回原始任务目标，历史列表不再使用长答案作为标题。
- 新增失败恢复入口、会话过期处理和健壮的 SSE 分块解析；修复模型在生成计划前失败后无法正确恢复的问题。
- 增加后端工作台与恢复回归测试、前端状态与网络回归测试，并接入 CI。

## 0.2.0 Week 2

- 引入 Alembic 唯一迁移路径、环境分级和就绪检查。
- 新增 JWT、RBAC、租户隔离、审计和 v2 API。
- 新增可替换模型 Provider、LLM 调用与估算成本记录、SSE 执行事件。
- 收紧 agent01 契约、来源模型、稳定错误和提示注入边界。
- 新增 React TypeScript 控制台、任务历史、轨迹和审批界面。
- 新增 Prometheus 指标、租户运行摘要、50 条评测和自动验收脚本。

已知限制：真实模型和真实 agent01 验收需要外部凭据；Search、Calendar 和 Task 仍是可替换的本地适配器；未实现分布式 Worker。
